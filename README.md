# finbot — シャープレシオ最大化型・多資産トレーディングボット

多資産ポートフォリオを対象に、**リスク調整後リターン(シャープレシオ)の最大化**を
設計目標としたトレーディングボットです。バックテスト・CPCV/ウォークフォワード検証・
ペーパートレードがすべて同一のロジック(`compute_target_weights`)を共有します。

設計の根拠と文献は **[docs/DESIGN_V2.md](docs/DESIGN_V2.md)** を参照してください
(学術・実務研究の網羅的調査に基づく改訂設計書。各コンポーネントの採用理由と
「やらないこと」の理由を信頼度つきで記載)。

## 設計思想(v2)

個別銘柄の価格予測で勝とうとするのではなく、実証的に OOS シャープを動かす
4 つのレバー — 直交シグナル・コスト効率・ブレッドス・過学習排除 — に集中します。

| 要素 | 実装 |
|---|---|
| **多資産分散**(8 資産、拡張可能) | 低相関資産の組み合わせはシャープを乗数的に改善する唯一最大のレバー |
| **トレンドシグナル**(Baz et al. 2015) | EWMAC 3 ペア (8,24)/(16,48)/(32,96) + 応答関数 z·e^(−z²/4)。連続シグナルでターンオーバーを抑えネットシャープを改善 |
| **キャリーシグナル**(Koijen et al. 2018) | リスク調整キャリーを EWMA 平滑化。トレンドと低相関の直交収益源 |
| **フォーキャスト統合層**(Carver 規約) | 各シグナルを E\|f\|=10 にスケール・±20 キャップ、トレンド 60 / キャリー 40 + FDM で統合 |
| **リスク推定の分離** | ボラ = 短期 EWMA(HL20日)×0.7 + 長期アンカー×0.3 / 相関 = HL200日 + 定相関シュリンク、Σ = D·C·D |
| **ボラティリティ・ターゲティング**(年率 10%) | リスク量を一定化。シャープ改善は株式系スリーブ、全資産でテール削減 |
| **コスト制御** | ポジションバッファ(平均ポジション±10%、帯の端まで最小調整)+ 部分調整。コストは 2bps でモデル化 |
| **CPCV + Deflated Sharpe 検証** | OOS シャープの「分布」と PBO(過学習確率)、試行数でデフレートした DSR を報告 |

v1 にあった **ドローダウン・ブレーキとクロスセクショナル・モメンタムは実証に基づき撤廃**
しました(ボラターゲット+トレンドが既にデレバレッジを内包しており、追加ブレーキは
シャープに中立〜マイナス。詳細は設計書 §2.2 / §6)。

## セットアップ

```bash
pip install -r requirements.txt
python -m pytest tests/ -v   # 45 テスト(先読みバイアス検証を含む)
```

## 使い方

```bash
# インサンプル・バックテスト(合成データ)
python -m finbot backtest

# CPCV + Deflated Sharpe ← モデル選択・過学習診断はこちら
python -m finbot cpcv

# ウォークフォワード OOS 評価(時系列順の最終確認)
python -m finbot walkforward

# ペーパートレード 1 ティック(日次 cron 実行を想定)
python -m finbot paper --state paper_state.json

# 実データ(CSV)で実行。キャリー(年率)CSV は任意
python -m finbot backtest --source csv --csv-path prices.csv --carry-csv carry.csv
```

CSV フォーマット: 1 列目が日付、以降が資産ごとの終値。キャリー CSV も同形式で、
値は年率の期待キャリー(例: 0.03 = 年率 3%。株式 = 配当利回り−短期金利、
債券 = 利回り+ロールダウン−短期金利、先物 = ロールイールド)。

```csv
date,EQ_US,BOND_GOV,GOLD
2020-01-02,100.0,50.0,150.0
```

## アーキテクチャ

```
finbot/
├── config.py        # BotConfig: 全パラメータ(文献の標準値に固定、自由度は最小)
├── data/            # DataSource 抽象化(synthetic / csv / yfinance)。load_carry() は任意
├── signals/         # trend: Baz et al. EWMAC / carry / ensemble: フォーキャスト統合層
├── risk/            # ボラ・相関の分離推定(covariance)+ ボラターゲット
├── portfolio/       # compute_target_weights: 全パイプラインの中核
├── backtest/        # エンジン(T 日シグナル → T+1 日適用)・指標(PSR/DSR)・cpcv・walkforward
└── live/            # PaperBroker + 日次ティックランナー
```

### 先読みバイアスの排除

- `compute_target_weights` の t 行は **t 日終値までの情報のみ**で計算
  (フォーキャストのスケーラも因果的な expanding 推定)
- エンジンは「前日終値で建てたポジション × 当日リターン」で損益を計上
- テスト `test_no_lookahead` / `test_weights_causality` が「未来の価格を改変しても
  過去の結果が 1 bit も変わらない」ことを機械的に検証

### 検証プロトコル(設計書 §7)

1. 設計比較・パラメータ感度は `cpcv`(N=10 グループ, k=2 → 45 分割・9 本の OOS パス)
2. 採用基準: **DSR > 0.95 かつ PBO ≲ 0.2**。グリッドを増やすほど DSR は自動的に厳しくなる
3. `walkforward` は時系列順の現実的シミュレーションとして最終確認に使う
4. 実データでは直近 3-5 年を開発中は触らないホールドアウトとして残し、設計凍結後に 1 回だけ評価する

### 実運用への差し替え

1. **データ**: `finbot/data/yfinance_source.py` の `YFinanceSource` を使うか、
   `DataSource` を継承して任意の API アダプタを実装(`load()` が終値 DataFrame を返すだけ。
   `load_carry()` を実装すればキャリースリーブが自動で有効になる)
2. **執行**: `PaperBroker` と同じインタフェース(`portfolio_value` / `rebalance_to`)で
   実ブローカのアダプタを実装
3. 日次の場中終了後に `python -m finbot paper` 相当の処理を cron で実行

## 重要な注意事項

- **本ソフトウェアは将来の運用成績・シャープレシオを一切保証しません。**
  バックテストの数値は(OOS 評価であっても)過去データに対するものです。
- 同梱の合成データはレジーム切替・相関構造を持つ現実的な乱数ですが、実市場ではありません。
  実データでの CPCV/ウォークフォワード評価と十分なペーパートレード期間を経ずに
  実資金を投入しないでください。
- 投資判断は自己責任で行ってください。本リポジトリは投資助言ではありません。
