# finbot — シャープレシオ最大化型・多資産トレーディングボット

多資産ポートフォリオを対象に、**リスク調整後リターン(シャープレシオ)の最大化**を
設計目標としたトレーディングボットです。バックテスト・ウォークフォワード検証・
ペーパートレードがすべて同一のロジック(`compute_target_weights`)を共有します。

## 設計思想

個別銘柄の価格予測で勝とうとするのではなく、学術・実務の両方で再現性が
報告されている要素を積み上げてシャープレシオを押し上げます。

| 要素 | 効果 |
|---|---|
| **多資産分散**(株式・債券・金・コモディティ等 8 資産) | 低相関資産の組み合わせはポートフォリオのリスクを下げ、シャープを機械的に改善する |
| **モメンタム・アンサンブル**(時系列 21/63/126/252 日 + クロスセクショナル) | 単一ルックバックへの過学習を回避しつつトレンドを捕捉 |
| **リスクパリティ配分**(逆 EWMA ボラ加重) | 特定資産へのリスク集中を防ぐ |
| **ボラティリティ・ターゲティング**(年率 10%) | リスク量を一定化。シャープの分母を安定させる実証的に強い手法 |
| **ドローダウン・ブレーキ** | DD が深くなるほどエクスポージャを線形縮小し、テール損失の複利的拡大を抑制 |
| **コスト制御**(リバランスバンド + ウェイト EWMA 平滑化) | ターンオーバーを抑えコストドラッグを削減(取引コストは 5bps でモデル化) |
| **ウォークフォワード検証** | 「見せかけのシャープ」を排除し、アウトオブサンプルの数値だけを信頼する |
| **リバランス・トランチング**(5 本の位相分散、`--tranches`) | リバランス日の選び方という運要素(Rebalance Timing Luck)を平均化で除去。期待リターンを変えずに分散だけ下げるフリーランチ |
| **Yang-Zhang レンジボラ推定**(OHLC があるとき自動有効、`--no-range-vol` で無効化) | 高値・安値・始値を使う推定は終値のみより統計効率が数倍高く、ボラターゲットの分母が滑らかかつ速く真のボラに追随する |
| **Gârleanu-Pedersen 部分調整**(`--no-gp` で無効化) | コスト存在下の最適執行(JF 2013)。エイムへ毎日一定割合だけ近づき、エイム側では減衰の遅いシグナルを過大評価。ターンオーバーを構造的に削減 |

## セットアップ

```bash
pip install -r requirements.txt
python -m pytest tests/ -v   # 52 テスト(先読みバイアス検証を含む)
```

## 使い方

```bash
# インサンプル・バックテスト(合成データ)
python -m finbot backtest

# ウォークフォワード OOS 評価 ← 信頼すべきシャープレシオはこちら
python -m finbot walkforward

# ペーパートレード 1 ティック(日次 cron 実行を想定)
python -m finbot paper --state paper_state.json

# 実データ(CSV)で実行
python -m finbot backtest --source csv --csv-path prices.csv

# 新機能を無効化して従来挙動と比較
python -m finbot walkforward --tranches 1 --no-range-vol --no-gp
```

CSV フォーマット: 1 列目が日付、以降が資産ごとの終値。

```csv
date,EQ_US,BOND_GOV,GOLD
2020-01-02,100.0,50.0,150.0
```

## アーキテクチャ

```
finbot/
├── config.py        # BotConfig: 全パラメータ(自由度を意図的に小さく)
├── data/            # DataSource 抽象化(synthetic / csv / yfinance、OHLC は任意提供)
├── signals/         # 因果的モメンタムシグナル([-1, 1])+ GP 持続性重み
├── risk/            # EWMA 共分散・Yang-Zhang レンジボラ・ボラターゲット・DD ブレーキ
├── portfolio/       # compute_target_weights: 全パイプラインの中核 + GP 部分調整
├── backtest/        # エンジン(T 日シグナル → T+1 日適用・トランチング)・指標・walkforward
└── live/            # PaperBroker + 日次ティックランナー
```

### 先読みバイアスの排除

- `compute_target_weights` の t 行は **t 日終値までの情報のみ**で計算
- エンジンは「前日終値で建てたポジション × 当日リターン」で損益を計上
- テスト `test_no_lookahead` / `test_weights_causality` が「未来の価格を改変しても
  過去の結果が 1 bit も変わらない」ことを機械的に検証

### 実運用への差し替え

1. **データ**: `finbot/data/yfinance_source.py` の `YFinanceSource` を使うか、
   `DataSource` を継承して任意の API アダプタを実装(`load()` が終値 DataFrame を返すだけ)
2. **執行**: `PaperBroker` と同じインタフェース(`portfolio_value` / `rebalance_to`)で
   実ブローカのアダプタを実装
3. 日次の場中終了後に `python -m finbot paper` 相当の処理を cron で実行

## 重要な注意事項

- **本ソフトウェアは将来の運用成績・シャープレシオを一切保証しません。**
  バックテストの数値は(OOS 評価であっても)過去データに対するものです。
- 同梱の合成データはレジーム切替・相関構造を持つ現実的な乱数ですが、実市場ではありません。
  実データでのウォークフォワード評価と十分なペーパートレード期間を経ずに
  実資金を投入しないでください。
- 投資判断は自己責任で行ってください。本リポジトリは投資助言ではありません。
